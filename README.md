## 🧑‍💻 About me

- 🛠️ I build web applications **end to end** — UI, real-time backends, databases, deployment and CI/CD.
- 🎮 I specialise in **real-time & multiplayer systems**: WebSocket / Socket.IO game servers, server-authoritative game logic and anti-cheat.
- 🎙️ I work with **voice & WebRTC**: LiveKit SFU, peer-to-peer mesh, TURN relays and spatial audio.
- 🔐 I'm **security-minded**: CSP, rate limiting, signed sessions, and automated security scanning (CodeQL, Trivy) in CI.
- 🚀 Currently building **[LobbyForge](https://github.com/Juanka-e/LobbyForge)** — a self-hostable, voice-first community platform (closed beta).
